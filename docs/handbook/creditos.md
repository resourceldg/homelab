## Tecnologías

Este sistema se apoya en software libre: Ubuntu, Docker, Ansible, Mosquitto,
Node-RED, Grafana, Prometheus, VictoriaMetrics, Telegraf, PostgreSQL, Caddy,
Authelia, MicroPython y el ecosistema Arduino, entre otros. Cada uno tiene sus
propios autores y licencias.
